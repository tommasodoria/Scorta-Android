Importa inventario CSV

Carica un file CSV esportato da Scorta o con intestazioni compatibili. L'importazione sostituisce prodotti, movimenti e vendite esistenti.

Prima di importare, salva un backup JSON dei dati correnti.

Stampa e listino prezzi

Seleziona soltanto i prodotti desiderati e scegli se stampare il listino prezzi o l’inventario con giacenze.

Privacy e salvataggio. I dati vengono memorizzati solo nel browser di questo dispositivo: non esiste sincronizzazione automatica tra telefoni o computer. Se cancelli i dati del browser o cambi dispositivo senza backup, potresti perderli. Per un uso aziendale condiviso è necessario collegare un database online.
